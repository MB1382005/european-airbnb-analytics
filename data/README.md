# Dataset

This folder contains the 20 original CSV files used in the project: weekday and weekend data for 10 European cities. There are 51,707 rows in total, excluding headers.

For SQL import, copy the files to `C:\AirbnbData\` or update the import paths. See [the data inventory](../docs/data-inventory.md) for row counts. The original source link and redistribution terms have not yet been documented.
